# @joralvmel/cosmos-icons

Icons for [Cosmos UI](../../README.md).

> Status: early development. The API below is the current skeleton.

Structured, framework-neutral icon definitions. The Lucide-based icon set and the `<cosm-icon>`
renderer are planned ([ADR 0005](../../docs/adr/0005-icons-lucide.md)).

```ts
import { isIconDefinition, type IconDefinition } from '@joralvmel/cosmos-icons';
```
