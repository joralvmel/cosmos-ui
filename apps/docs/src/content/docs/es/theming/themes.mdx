Cada tema se genera a partir de colores semilla y una armonía de color con `defineTheme`. El motor crea
escalas OKLCH de 12 pasos, un modo dark con su propia curva de luminosidad, colores de estado que
conservan su significado y una paleta de 8 colores para gráficas. Cada tema se valida con WCAG 2.2 AA
(normativo), APCA (informativo) y simulaciones de protanopia, deuteranopia y tritanopia.

## Elegir un tema incluido

| Tema | Color principal | Carácter |
| --- | --- | --- |
| Cosmos | Azul zafiro | La base equilibrada y predeterminada |
| Nebula | Morado amatista | Expresivo y frío |
| Terra | Verde bosque | Natural y fresco |
| Supernova | Rojo coral | Cálido y enérgico |
| Aurora | Cian/turquesa | Claro y luminoso |
| Solstice | Ámbar/dorado | Cálido y equilibrado |

Cada paleta incluye modos claro y oscuro en web y React Native. Las nuevas paletas usan el radio
estándar; la tipografía, el espaciado y el movimiento no cambian. Cosmos sigue siendo el predeterminado.
Success, warning, danger e info conservan su significado semántico: un color principal verde o rojo
es una elección de marca, no un resultado de validación. Acompaña siempre los colores de estado
con texto o iconos que comuniquen su significado.

Elige un tema en la cabecera del sitio para aplicarlo a las vistas previas y los controles compartidos
del Playground. El Playground permite fijar su propio tema y modo; selecciona las opciones del sitio
para volver a seguir la cabecera. La galería muestra cada paleta en ambos modos de forma independiente.

En una aplicación, usa el runtime existente:

```ts
import { setMode, setTheme } from '@joralvmel/cosmos-tokens/runtime';

setTheme('terra');
setMode('system');
```

En React Native, usa `<CosmosThemeProvider theme="terra" mode="system">`; la pantalla principal
de la demo nativa incluye los mismos temas. Tailwind ofrece una variante `theme-<name>:` para cada
paleta, como `theme-terra:bg-primary-subtle`.

## Crear un tema

```ts
import { defineTheme, resolveTheme, toCss, validateTheme } from '@joralvmel/cosmos-tokens';

const studio = defineTheme({
  name: 'studio',
  seeds: { primary: 'oklch(0.56 0.15 165)' },
  harmony: 'triadic',
  radius: 'pill',
});

const resolved = resolveTheme(studio);
console.log(validateTheme(resolved).pass);
const css = toCss([resolved]);
```

Un tema no puede llamarse `light`, `dark` ni `system`; son nombres de modo.

## Conservar una paleta existente

Para reutilizar los colores de un producto existente, úsalos como semillas y fija los valores
exactos por rol semántico y modo. `validateTheme` sigue comprobando cada par; si uno falla, ajusta
ese valor en lugar de rebajar el requisito.

```ts
const brand = defineTheme({
  name: 'brand',
  seeds: { primary: '#2f6fed', accent: '#f59e0b' },
  modes: {
    light: { primary: '#2f6fed', bg: '#ffffff', surface: '#f6f7f9', fg: '#111827' },
    dark: { primary: '#7aa2ff', bg: '#0b1020', surface: '#151b2e', fg: '#e5e7eb' },
  },
});

console.log(validateTheme(resolveTheme(brand)).pass);
```

La tipografía, el espaciado y el movimiento no son entradas del tema. Para que un asistente mapee
una paleta por ti, consulta [usar una referencia](../../contribute/prompt-cookbook/#usar-una-referencia).
