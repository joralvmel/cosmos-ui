Each theme is generated from seed colors and a color harmony with `defineTheme`. The engine builds
12-step OKLCH scales, a dark mode with its own lightness curve, status colors that keep their meaning and
an 8-color chart palette. Every theme is validated against WCAG 2.2 AA (normative), APCA (informative)
and simulated protanopia, deuteranopia and tritanopia.

## Choose a built-in theme

| Theme | Primary color | Character |
| --- | --- | --- |
| Cosmos | Sapphire blue | The default, balanced foundation |
| Nebula | Amethyst purple | Expressive and cool |
| Terra | Forest green | Grounded and fresh |
| Supernova | Coral red | Warm and energetic |
| Aurora | Cyan/turquoise | Clear and luminous |
| Solstice | Amber/gold | Warm and balanced |

Every palette includes light and dark modes on web and React Native. All built-in themes share the
`rounded` radius preset; typography, spacing and motion also stay unchanged. Cosmos remains the default.
Success, warning, danger and info keep their semantic meaning: a green or red primary is a brand
choice, not a validation result. Always pair status color with meaningful text or icons.

Choose a theme in the site header to apply it to the previews and shared Playground controls.
The Playground can override theme and mode independently; choose the site options to follow the
header again. The gallery below deliberately shows each palette in both modes.

For an application, use the existing runtime:

```ts
import { setMode, setTheme } from '@joralvmel/cosmos-tokens/runtime';

setTheme('terra');
setMode('system');
```

In React Native, set `<CosmosThemeProvider theme="terra" mode="system">`; the native demo
lists the same themes on its home screen. Tailwind includes a `theme-<name>:` variant for each
palette, such as `theme-terra:bg-primary-subtle`.

## Create a theme

```ts
import { defineTheme, resolveTheme, toCss, validateTheme } from '@joralvmel/cosmos-tokens';

const studio = defineTheme({
  name: 'studio',
  seeds: { primary: 'oklch(0.56 0.15 165)' },
  harmony: 'triadic',
  radius: 'pill',
});

const resolved = resolveTheme(studio);
console.log(validateTheme(resolved).pass);
const css = toCss([resolved]);
```

Theme names cannot be `light`, `dark` or `system`; those are mode names.

## Keep an existing palette

To reuse the colors of an existing product, use them as seeds and set the exact values per
semantic role and mode. `validateTheme` still checks every pair; when one fails, adjust that value
instead of lowering the requirement.

```ts
const brand = defineTheme({
  name: 'brand',
  seeds: { primary: '#2f6fed', accent: '#f59e0b' },
  modes: {
    light: { primary: '#2f6fed', bg: '#ffffff', surface: '#f6f7f9', fg: '#111827' },
    dark: { primary: '#7aa2ff', bg: '#0b1020', surface: '#151b2e', fg: '#e5e7eb' },
  },
});

console.log(validateTheme(resolveTheme(brand)).pass);
```

Typography, spacing and motion are not theme inputs. To have an assistant map a palette for you,
see [use a reference](../../contribute/prompt-cookbook/#use-a-reference).
