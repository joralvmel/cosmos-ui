`<cosm-button>` ejecuta una acción. Sigue el
[patrón de botón de WAI-ARIA](https://www.w3.org/WAI/ARIA/apg/patterns/button/), renderiza un
`<button>` nativo y participa en formularios (`type="submit"` / `type="reset"`).

`loading` mantiene el botón enfocable, establece `aria-busy` e ignora las pulsaciones. `disabled` lo
saca del orden de tabulación.

## Uso por plataforma

```tsx
// React
<Button variant="soft" onPress={event => guardar(event.detail.source)}>Guardar</Button>
```

```html
<!-- Angular -->
<cosm-button variant="soft" (press)="guardar($event.detail.source)">Guardar</cosm-button>
```

```tsx
// React Native
<Button variant="soft" onPress={({ source }) => guardar(source)}>Guardar</Button>
```

## Accesibilidad

- Da a los botones solo con icono un `label`; se convierte en el nombre accesible.
- Usa `tone="danger"` junto con un texto explícito en acciones destructivas; el color nunca es la única señal.
- En React Native, los botones pequeños amplían su área táctil a 44 puntos.
