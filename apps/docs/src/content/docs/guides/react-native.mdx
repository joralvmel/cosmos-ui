## Theme and mode

`CosmosThemeProvider` accepts `theme` (`cosmos`, `nebula`…) and `mode` (`light`, `dark` or `system`,
which follows the device appearance).

## Your own styles with the theme

```tsx
import { useTheme } from '@joralvmel/cosmos-native';
import { Text, View } from 'react-native';

export function Card({ title }: { title: string }) {
  const theme = useTheme();
  return (
    <View style={{ backgroundColor: theme.colors.surface, borderRadius: theme.radius.lg, padding: theme.space.lg }}>
      <Text style={{ color: theme.colors.fg, fontSize: theme.text.lg }}>{title}</Text>
    </View>
  );
}
```

## Accessibility

Components set `accessibilityRole`, `accessibilityState` and labels, and small controls extend their
touch area to 44 points. Test with TalkBack and VoiceOver.
