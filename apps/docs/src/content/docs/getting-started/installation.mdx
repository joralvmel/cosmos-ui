      return (

        </CosmosThemeProvider>
      );
    }

## Theme and mode

Set the theme and mode on any element (usually `<html>`). `data-mode="system"` follows the operating
system; without `data-mode` the light mode is used.

```html
<html data-theme="nebula" data-mode="system"></html>
```

## Tailwind CSS v4 (optional)

```css
@import "tailwindcss";
@import "@joralvmel/cosmos-tailwind";
```

Utilities such as `bg-primary`, `text-fg-muted`, `rounded-md`, `dark:bg-surface` or
`theme-nebula:text-accent` use the Cosmos tokens.
