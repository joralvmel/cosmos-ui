# @joralvmel/cosmos-charts

Chart Web Components for [Cosmos UI](../../README.md).

> Status: early development. The API below is the current skeleton.

Chart Web Components (SVG + Lit) built on `@joralvmel/cosmos-charts-core`. Currently exposes the
shared layout helpers and `seriesColor(index)` (`var(--cosm-chart-n)`).
