`<cosm-icon>` renders a structured SVG definition. Import only the glyphs you use from
`@joralvmel/cosmos-icons`; per-icon modules keep application bundles tree-shakeable.

## Playground

<Playground name="icon" content="" />

Search all 2,052 icons by name, category or tag; choose a result to load only that artwork.
Try `heart` or `star`, then edit `stroke`, `fill`, `strokeWidth`, and `size` independently.

## Variants

Choose `sm` (16), `md` (20, default), `lg` (24), or a positive finite number. Numbers are CSS
pixels on the web and logical units on native. On the web `--cosm-icon-size` takes precedence,
including `em` and `rem` values; it does not apply to native.

```tsx
import { Icon } from '@joralvmel/cosmos-react';
import { house } from '@joralvmel/cosmos-icons/house';

<Icon icon={house} size="lg" />;
```

`stroke` defaults to `currentColor` (inherited on web, `theme.colors.fg` on native), `fill` to
`none`, and `strokeWidth` to `2` SVG viewBox units. Stroke width scales with the icon. Use
nonnegative finite widths. Paints must be supported by the platform; URL paints are rejected.
CSS custom-property paints work on the web, while native requires React Native color strings.

```tsx
import { heart } from '@joralvmel/cosmos-icons/heart';

<Icon icon={heart} size={32} stroke="var(--cosm-fg)" fill="var(--cosm-surface)" strokeWidth={1.5} />;
```

In React Native use `const theme = useTheme()` and pass `stroke={theme.colors.fg}` and
`fill={theme.colors.surface}` instead. An explicit fill on a definition node takes precedence
over the root fill, including `none` on transparent nodes. Heart and star have compatible geometry
for a filled example; not every Lucide icon has a solid variant. On native, a definition node
whose fill is `currentColor` (for example the dots of `brain-circuit`) also uses
`theme.colors.fg`, independently of `stroke`. The Playground accepts `none`, `currentColor`, Cosmos
color tokens such as `var(--cosm-primary)` and hex/rgb/hsl/named colors so every tab is valid; its
React Native tab turns token paints into `theme.colors` values from `useTheme()`.

## States

Icons are non-interactive and have no state or events. They are decorative by default. To convey
meaning, set `decorative={false}` and provide a concise `label`.

```tsx
<Icon icon={house} decorative={false} label="Home" />;
```

## Accessibility

- Decorative icons are hidden from assistive technology and are not focusable.
- Informative icons expose one image role and the provided accessible name.
- `decorative={false}` without a non-empty `label` is an error; add a label or keep the icon
  decorative.
- Do not use an icon alone as an interactive control. Put it inside a separately labeled button.
