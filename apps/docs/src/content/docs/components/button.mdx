`<cosm-button>` triggers an action. It follows the
[WAI-ARIA button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/), renders a native
`<button>` and takes part in forms (`type="submit"` / `type="reset"`). Use it for actions; use a link
for navigation.

## States

<Preview>
  <cosm-button loading>Saving</cosm-button>
  <cosm-button disabled>Disabled</cosm-button>
</Preview>

- `loading` keeps the button focusable, sets `aria-busy` and ignores presses.
- `disabled` removes it from the tab order and ignores presses.
- Hover, active and `:focus-visible` states use the theme tokens of the selected tone.

## Accessibility

- Native `<button>` semantics: <kbd>Enter</kbd> and <kbd>Space</kbd> activate it.
- Give icon-only buttons a `label`; it becomes the accessible name.
- Use `tone="danger"` together with explicit text for destructive actions; color is never the only cue.
- On React Native, small buttons extend their touch area to 44 points.
