# @joralvmel/cosmos-mcp

MCP server for [Cosmos UI](../../README.md).

> Status: early development. The API below is the current skeleton.

Model Context Protocol server that will expose Cosmos components, tokens and themes to AI assistants.
The data layer is available today:

```ts
import { getComponent, listComponents, listThemes } from '@joralvmel/cosmos-mcp';
```
