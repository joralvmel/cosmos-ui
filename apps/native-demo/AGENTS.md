# AGENTS.md — native demo

Read the root [AGENTS.md](../../AGENTS.md) and `.github/instructions/native.instructions.md`.

- Expo Router app: one screen per component in `app/<name>.tsx`, listed in `src/screens.ts`.
- The home screen switches theme and mode for every screen.
- Run with `npm run dev --workspace=@joralvmel/cosmos-native-demo` (Expo Go or a simulator).
- Validate with `npx turbo run typecheck --filter=@joralvmel/cosmos-native-demo`.
